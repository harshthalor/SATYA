# Server Core

Node.js/Go Universal Translator API - The central orchestration layer.

## Features
- Cross-state voter data translation
- API gateway for all services
- Blockchain integration
- AI authentication service integration

## Tech Stack
- Node.js (or Go)
- Express/FastAPI (depending on language choice)
- REST/GraphQL API

## Getting Started

### Node.js
```bash
npm install
npm start
```

### Go
```bash
go mod init
go run main.go
```
