# Models Directory

This directory contains pre-trained FaceNet models for facial recognition.

## Supported Formats
- `.h5` - Keras/TensorFlow HDF5 format
- `.pb` - TensorFlow Protocol Buffer format
- `.pth` - PyTorch format (if using PyTorch)

## Model Files
Place your FaceNet model files here. The models will be loaded by the FaceProcessor.

## Example Models
- `facenet_keras.h5` - Keras FaceNet model
- `facenet.pb` - TensorFlow FaceNet model
