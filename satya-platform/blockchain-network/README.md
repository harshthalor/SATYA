# Blockchain Network

Hyperledger Fabric chaincode and network configuration.

## Features
- Immutable voter identity records
- Cross-state voter data synchronization
- Smart contracts for voter verification
- Decentralized trust mechanism

## Tech Stack
- Hyperledger Fabric
- Chaincode (Go/JavaScript)
- Network configuration files

## Getting Started

```bash
# Start Fabric network
./network.sh up

# Deploy chaincode
./network.sh deployCC
```
